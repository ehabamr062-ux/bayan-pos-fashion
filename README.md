## 📖 نبذة عن النظام (About The Project)
**نظام بَيَان POS فاشون** هو نظام هجين متطور (Hybrid POS) مصمم بأحدث التقنيات البرمجية لتلبية كافة احتياجات **محلات ومصانع الملابس، الأحذية، الإكسسوارات، وسلاسل الفاشون التجارية**. 

يجمع النظام بين استقرار برامج سطح المكتب (Desktop App عبر Electron) وخفة وسرعة تطبيقات الويب (PWA عبر IndexedDB و Node.js Server Hub)، مما يتيح ربط اللابتوب الرئيسي بأجهزة التابلت والموبايل داخل نفس شبكة الواي فاي المحلية ومزامنة المبيعات والمخازن والحسابات لحظياً في أجزاء من الثانية وبدون أي اشتراكات سحابية إجبارية.

## ✨ أبرز مميزات النظام (Key Features)

### 👗 1. محرك الفاشون وإدارة المقاسات والألوان (Fashion Matrix)
* **مصفوفة المقاسات والألوان:** توليد وتتبع كروت المقاسات (S, M, L, XL, XXL) والألوان لكل صنف بنقرة زر.
* **باركود مستقل لكل تشكيلة:** قراءة باركود المقاس واللون وسحبه فوراً في الفاتورة مع التمييز التلقائي.
* **سياسات تسعير متعددة:** دعم أسعار القطاعي، الجملة، ونصف الجملة.

### ⚡ 2. نقطة بيع وكاشير فائق السرعة (POS Cashier)
* **قراءة ليزرية سريعة (<50ms):** تمييز أجهزة قراءة الباركود اللاسلكية والسلكية وإضافة الأصناف فوراً للسلة.
* **التبويبات المتعددة (Multi-Tabs):** فتح أكثر من فاتورة بيع بالتوازي مع صمام أمان يمنع إغلاق البرنامج في حال وجود سلة غير محفوظة.
* **إدارة الورديات وجرد الخزينة:** مطابقة النقدية في الدرج مع المبيعات المحسوبة نهاية كل وردية.

### 📦 3. المخازن والتحويلات اللحظية (Multi-Warehouse & Transfers)
* **عزل أرصدة الفروع:** كل كاشير يبيع ويشاهد المخزن المخصص له فقط.
* **دورة التحويل مع ساحة الانتظار (In-Transit Queue):** إرسال إذن التحويل ➔ تنبيه الفرع المستلم ➔ استلام وتأكيد البضاعة بالباركود.
* **طباعة أذونات التحويل والـ PDF:** طباعة كاملة للمقاسات والألوان في إذن التحويل وتوقيعات الاستلام.

### 🏷️ 4. محرك طباعة وتوسيط الباركود (Barcode Engine)
* **توسيط دقيق وهوامش أمان (`margin: 3`):** منع تآكل خطوط الباركود على الطابعات الحرارية لضمان قراءة السكانر الفورية.
* **دعم كافة المقاسات:** (50×25 مم، 40×25 مم، 38×25 مم) مع إمكانية إخفاء الحقول وتكبير الخطوط.
* **دعم موازين الملابس بالكيلو:** قراءة باركود الميزان الإلكتروني (EAN-13) وتفكيك الوزن والسعر تلقائياً.

### 🌐 5. السيرفر المدمج والربط مع التابلت (Local Network & PWA)
* **سيرفر محلي مدمج على المنفذ `4545`:** يعمل اللابتوب الرئيسي كسيرفر مركزي بدون الحاجة للإنترنت.
* **مزامنة فورية ثنائية الاتجاه:** حفظ فوري في قاعدة بيانات اللابتوب الرئيسي عند البيع من أي تابلت.
* **تشغيل أوفلاين كامل (PWA Service Worker):** استمرار التابلت في العمل عند انقطاع الشبكة بدون أي توقف.

### 💼 6. الحسابات والماليات والأمان (Finance & Security)
* **كشوفات حساب تفصيلية للعملاء والموردين:** تصدير فوري إلى Excel و PDF والمشاركة عبر WhatsApp.
* **حماية التراخيص بـ `HMAC SHA-256`:** ربط كود التفعيل ببصمة الجهاز (HWID).
* **حماية ضد التلاعب بالتاريخ:** اكتشاف تأخير ساعة الويندوز وحظر الدخول تلقائياً.

## 🛠️ البنية التقنية (Tech Stack)

* **الواجهة الأمامية (Frontend):** HTML5, Vanilla JavaScript (ES6+), Vanilla CSS (High-Performance Modular Architecture).
* **قاعدة البيانات المحلية (Database):** `Dexie.js` (IndexedDB Engine) — سرعة فائقة وتحمل مئات الآلاف من الفواتير.
* **السيرفر المدمج (Local Server):** Node.js HTTP REST Engine (`server_hub.js`).
* **محرك الديسكتوب (Desktop Core):** Electron Framework.
* **المكتبات المحلية (Local Offline Libraries):**
  * `Dexie.js` (قواعد البيانات غير المتزامنة)
  * `JsBarcode` (توليد الباركودات بدقة ليزر)
  * `QRCode.js` (توليد رموز الاستجابة السريعة)
  * `Chart.js` (الرسوم البيانية والإحصائيات)
  * `SheetJS (XLSX)` (تصدير واستيراد ملفات الإكسيل)
  * `html2canvas` (طباعة ومشاركة الفواتير كصور)

## 🚀 طريقة التشغيل والتطوير (Getting Started)

### 1. تشغيل نسخة الويب والتابلت محلياً:
```bash
# تشغيل السيرفر المحلي
npm start
# أو تشغيل السيرفر المدمج مباشرة عبر Node.js:
node server_hub.js
```

### 2. تثبيت التبعيات (Dependencies):
```bash
npm install
```

### 3. بناء ملف التثبيت النهائي للويندوز (.exe):
```bash
npm run package
```
*سيتم إنشاء ملف الـ Installer داخل مجلد `dist/` جاهزاً للتسليم والتوزيع.*

## 📱 ربط أجهزة التابلت والموبايل (Tablet Setup Guide)

1. تأكد من اتصال اللابتوب والتابلت على **نفس شبكة الواي فاي أو الراوتر**.
2. على التابلت أو الهاتف، افتح المتصفح (Google Chrome / Safari) واكتب الرابط:
   ```
   http://<IP_اللابتوب>:4545
   ```
   *(مثال: `http://192.168.1.15:4545`)*
3. اضغط على **"تثبيت التطبيق / Install App"** أو **"إضافة إلى الشاشة الرئيسية"**.
4. أدخل رمز الـ PIN الظاهر على شاشة اللابتوب الرئيسي لإتمام الإقران بنجاح.
